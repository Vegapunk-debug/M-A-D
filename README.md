## 📘 About the App

**LearnLoop** is a React Native + Expo mobile application where users can:

- List **skills they can teach**
- List **skills they want to learn**
- Match with users having complementary skill interests
- Exchange skills through **free** or **barter-based learning**
- Grow together in a community-driven skill ecosystem

It creates an endless loop of teaching, learning, and improving.

---

## 🚀 Features

### 🏠 Home
- Personalized skill recommendations  
- Trending and popular skills  
- Quick actions (Add skill, Explore, Edit Profile)  

### 🔍 Explore
- Browse skills across categories  
- Search skills  
- Filters for skill level  
- View detailed user profiles  

### ➕ Add Skills
- Add skills you can **Teach**  
- Add skills you want to **Learn**  
- Add descriptions and experience levels  

### 👤 Profile
- Edit personal info  
- Manage your teaching/learning skills  
- View suggested matches  
- Profile completion indicator

## 🔥 Skill Matching System

LearnLoop’s matchmaking algorithm pairs users based on:

- Teach ↔ Learn skill matching  
- Experience level  
- Skill category  
- Optional preferences  
- Activity history
